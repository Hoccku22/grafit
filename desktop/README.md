# Графит — десктопная версия

«Графит» как настоящее приложение для Windows: своё окно, свой значок, фирменная шапка. Интерфейс — тот же, что в веб-версии, один в один (общая кодовая база в `app/`).

**Готовые сборки** (portable и установщик) можно скачать в разделе [Releases](https://github.com/Hoccku22/grafit/releases).

## Готовые файлы (dist/)

- **Графит-0.2.2-portable.exe** (~95 МБ) — портативная версия: один файл, ничего не устанавливает. Двойной клик — и программа открылась. Можно носить с собой.
- **Графит-0.2.2-setup.exe** (~96 МБ) — установщик: ставит «Графит» как обычную программу, создаёт ярлыки в меню «Пуск» и на рабочем столе.

## Разработка

```powershell
npm install        # один раз
npm start          # запустить окно без сборки
npm run smoke      # автопроверка (окно скрыто): SMOKE_OK
npm run shot       # автопроверка + снимок окна (shot.png)
npm run icon       # пересобрать значок (build/icon.png)
npm run dist       # собрать dist/ (портативный + установщик)
```

Требования: Node.js. Electron и electron-builder ставятся локально в `node_modules`, ничего системного не трогают.

## Движок (Ollama) — как модуль

Программа сама находит движок в таком порядке:

1. `grafit.config.json` рядом с программой (пути могут быть относительными — считаются от файла конфига);
2. папка `engine\ollama.exe` рядом с программой;
3. вверх по дереву папок: `grafit-portable\desktop\engine\ollama.exe` (наша сборка);
4. системный Ollama (`%LOCALAPPDATA%\Programs\Ollama`).

Движок запускается вместе с окном и останавливается при выходе программы. Модели лежат рядом с движком (`models\`); если в конфиге указанная папка моделей не существует, используется папка рядом с движком. Настраивать ничего не нужно.

## Окно

- Фирменная шапка: логотип и «Графит» слева, полосу можно тянуть мышью, двойной клик — развернуть.
- Кнопки окна системные (Windows), цвет подстраивается под тему приложения (светлая/тёмная).
- Обычный режим — со шапкой; рамка окна спрятана, resizing работает.

## Состав проекта

- `main.js` — окно, движок, файловые операции, CORS для локального Ollama, сборка.
- `preload.js` — нативные мостики: выбор папки как в проводнике, файловые операции, фирменная шапка.
- `app/` — приложение «Графит» (та же кодовая база, что и веб-версия).
- `build/icon.png` — значок (генерируется из фирменного SVG, `npm run icon`).
- `tools/gen-icon.js` — генератор значка.
- `dist/` — собранные файлы (создаётся командой `npm run dist`).

## Версии

- **0.2.2** — меню хранилища помещается в окно при любом размере: позиционирование с прижатием к краям и прокрутка при нехватке места.
- **0.2.1** — фирменные диалоги вместо системных окон; горячие клавиши работают в русской и английской раскладке; защита правок: одно окно на хранилище, восстановление ввода, запись при закрытии.
- **0.2.0** — сборка «как программа»: портативный `.exe` и установщик, свой значок, фирменная шапка окна, автопоиск движка с относительными путями, автопроверка упакованных сборок (`--smoke`, `--shot`, `--smoke-out`).
- **0.1.0** — первый прототип: окно Electron, запуск/остановка движка, системный выбор папки.
