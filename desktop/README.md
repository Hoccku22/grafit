# Графит — портативный комплект

Эта папка делает Ollama **модулем приложения**: движок ставится внутрь папки «Графита», а не в систему.

## Три файла

| Файл | Что делает |
|---|---|
| `Установить-Графит.cmd` | Скачивает портативную Ollama (~1.4 ГБ) в `desktop\engine`. Запускается один раз. |
| `Запустить-Графит.cmd` | Поднимает локальный движок (если выключен) и открывает «Графит» в браузере. |
| `Остановить-Графит.cmd` | Выключает движок приложения (другие экземпляры Ollama не трогает). |

## Где что лежит

- `desktop\engine\` — движок Ollama (можно удалить для «удаления Ollama» — система чистая).
- `desktop\models\` — скачанные модели (их можно переносить вместе с папкой приложения).
- Всё остальное — сама папка «Графита».

Ничего не устанавливается в реестр, Program Files или PATH. Полное удаление = удалить папку приложения.

## Как пользоваться

1. Запустите `Установить-Графит.cmd` один раз (нужно ~4 ГБ свободного места и интернет).
2. Запускайте `Запустить-Графит.cmd`.
3. В «Графите»: настройки ИИ (кнопка-искра) → сервис «Ollama (локально)» → «Локальная модель» → скачайте, например, `qwen2.5:1.5b`.
4. Всё, помощник работает мгновенно и офлайн.

## Мелочи

- Модели и движок работают только на этом компьютере — заметки синхронизируются как обычно (через облачную папку или GitHub).
- Если на компьютере уже запущен другой экземпляр Ollama на порту 11434 — «Графит» просто подключится к нему, ничего не ломая.
- Нужен Windows 10/11 и PowerShell (встроен). Скрипты лежат рядом — их всегда можно открыть и посмотреть, что они делают.
