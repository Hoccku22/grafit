# Проверка ИИ 0.5.6

Ollama 0.35.1 установлена официальным подписанным установщиком. Подготовка рекомендуемого ИИ проверена с настоящей установкой и скачиванием `qwen2.5:1.5b` и `qwen3:4b-instruct`. Компьютер: Windows, 16 ГБ RAM, NVIDIA RTX 3060 Laptop, 6 ГБ VRAM.

Реальная проверка выполнена 3 октября 2026 года через транспорт и инструкции приложения на синтетических данных. Пользовательские заметки не использовались.

| Пример | Время ответа | Результат |
| --- | ---: | --- |
| «Компьютер - это» | 4.61 с | Дописано определение без повторения начала |
| «Фотосинтез — это» | 0.79 с | Дописано определение без повторения начала |
| Структура конспекта | 1.12 с | Заголовки и абзацы, все предложения и числа сохранены |
| Теорема Пифагора | менее 0.01 с | Встроенная формула, условия и отображение проверены |
| Корни квадратного уравнения | менее 0.01 с | Встроенная формула и три случая дискриминанта проверены |
| Площадь треугольника через стороны и угол | 2.86 с | Модель выдала `S = ab sin(C) / 2`, обозначения и условия |

В загруженном состоянии первый фрагмент ответа появился через 0.06–0.26 с на этих примерах. Первый запуск или переключение моделей требует дополнительного времени; результаты не являются гарантией скорости на других компьютерах.

Ранние проверки выявили выдуманную дату и потерю предложения при полном переписывании конспекта. Структура переведена на план заголовков и группировки: итоговый текст собирается из исходника. Проверка отклоняет пропущенные фрагменты и изменённые числа. Для распространённых формул добавлен встроенный справочник после неточного объяснения двойного корня моделью.

Автоматические проверки: повторение начала, потоковые SSE/NDJSON ответы, таймаут и отмена, ограничение рекомендованных моделей, подпись установщика, повтор настройки, сохранение своих моделей, структура, числа, код и frontmatter, отображение формул, применение правок и Ctrl+Z. Проверки интерфейса запускаются в отдельном временном хранилище.

Достоверность произвольных ответов моделей не гарантируется этой ограниченной проверкой; результат остаётся доступным для просмотра перед применением.
