    О программе

    «Графит» — локальный редактор заметок в стиле Obsidian. Работает прямо в браузере, без сервера: данные хранятся только на ваших устройствах.

    Где хранятся заметки

    • Браузер — по умолчанию, в локальном хранилище (localStorage). Не забудьте про «Скачать резервную копию» в меню «⋯».
    • Облако — подключите папку Яндекс.Диска, Google Drive, Dropbox, OneDrive, Nextcloud и других сервисов: приложение пишет .md-файлы, а облачный клиент синхронизирует их между устройствами.
    • Папка на диске — обычная папка с .md-файлами (Chrome и Edge). Это и есть режим облачной синхронизации — просто укажите папку облачного клиента.

    Горячие клавиши

    • Ctrl+N — новая заметка
    • Ctrl+O — быстрый переход
    • Ctrl+Shift+F — поиск
    • Ctrl+E — режим просмотра
    • Ctrl+B / Ctrl+I — жирный / курсив
    • Ctrl+\ — инспектор
    • Ctrl+Shift+A — проверить текст с ИИ

    Сочетания работают в любой раскладке — и в русской, и в английской.

    О разметке

    Поддерживается Markdown, вики-ссылки [[Название]], теги #тег, чек-листы, таблицы и блоки кода.

    ИИ-помощник

    Необязательный помощник: подключите любой OpenAI-совместимый сервис (кнопка-искра в левой ленте) — он будет следить за текстом, подсказывать оформление, структуру и формулировки, исправлять опечатки и предлагать определения. Подсказки подсвечиваются прямо в тексте: поставьте курсор на подчёркнутый фрагмент — появится карточка с серым вариантом и кнопкой «Применить». Есть поддержка локальных моделей (Ollama). Работает на GitHub Pages и локально; на превью AutoClaw внешние запросы ограничены.

    Облачная синхронизация
    «Графит» пишет обычные .md-файлы в папку на компьютере, а приложение облака само синхронизирует её с вашими устройствами. Пароли, токены и OAuth не нужны — подходит почти любой сервис.
    Файлы остаются вашими: их можно открывать и править чем угодно — хоть в Obsidian, хоть в блокноте. «Графит» лишь читает и записывает эту папку.

    Свой тег
    Локальные модели работают без интернета и без ключей. Установите Ollama с сайта ollama.com и запустите её. Чтобы браузер мог к ней обращаться, разрешите запросы: выполните в PowerShell [Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS","*","User") и перезапустите Ollama. Затем выберите модель и нажмите «Скачать» — всё загрузится прямо отсюда.
    Подойдёт любой сервис с OpenAI-совместимым API: OpenRouter (есть бесплатные модели), OpenAI, Groq, локальный Ollama и другие. Ключ хранится только в этом браузере. Текст заметок отправляется выбранному сервису при проверке. Для локальной модели (Ollama) ключ не нужен — раздел появится при выборе сервиса «Ollama». На предпросмотре AutoClaw внешние запросы блокируются политикой хостинга — ИИ полностью работает в версии на GitHub Pages или локально.
